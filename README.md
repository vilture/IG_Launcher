# IG_Launcher
[Linux Appimage] Launcher Impressions Games
[Linux Appimage] Launcher Impressions Games

[b] Лаунчер для нативного запуска игр Impressions Games  [/b] 

[h3] Возможности [/h3] 
[list]
    [*] Запуск нативно игр под Linux через Appimage
    [*] Применение разрешения и вида окна игры (поддержка до 2К)
    [*] Локализация текста на русский язык (основан на руссифкаторах из ZOG) 
[/list] 

[h3] Поддерживаемые игры [/h3] 
[list]
    [*] Zeus: Master of Olympus + Poseidon
    [*] [url=github.com] Pharaoh + Cleopatra [/url] 
    [*] [url=github.com] Emperor: Rise of the Middle Kingdom [/url] 
[/list] 

[h3] Запуск [/h3] 
Поместите лаунчер в папку с игрой, или укажите путь до исполняемого .exe файла

[h3] Благодарность [/h3] 
Спасибо ZoneOfGames за предоставленную русификацию, на основе которой были доработаны локализации игр на русский язык.
